Turned an open-source federated learning simulator into a live
peer-to-peer system on 3 NVIDIA Jetson Orin Nanos. Built the gRPC/Protobuf
transport for asynchronous PyTorch model exchange, zero-config peer
discovery that scans ~16,000 addresses in 25 seconds, and a Docker image on
GHCR so a Jetson joins with one command.
